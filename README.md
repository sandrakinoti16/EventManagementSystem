# Event Management System

## Project Description
The Event Management System is a web application that allows users to view, register for, and manage events. Administrators can create, update, and delete events, while participants can register and receive event tickets.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- MySQL
- XAMPP
